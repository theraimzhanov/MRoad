# 📱 MRoad App

MRoad is a modern Android application designed to provide location-based features, map integration, and a smooth mobile experience. The app combines real-time data, local storage, and a clean user interface to deliver practical functionality.

---

## ✨ Features

- 🗺️ Google Maps integration
- 📍 Location-based services
- 🌐 API integration using Retrofit
- 💾 Local storage with Room Database
- 🧭 Navigation Component (Safe Args)
- 🖼️ Image loading (Glide & Picasso)
- ⚡ Coroutines for asynchronous operations
- 📱 Clean and responsive UI

---

## 🛠️ Tech Stack

- **Language:** Kotlin  
- **Architecture:** MVVM  
- **Dependency Injection:** Koin  
- **Networking:** Retrofit, Gson, OkHttp  
- **Database:** Room  
- **Maps & Location:** Google Maps SDK, Location Services  
- **UI:** ViewBinding, Material Design

## ▶️ How to Run

1. Clone the repository  
2. Open in Android Studio  
3. Add your Google Maps API key  
4. Sync Gradle  
5. Run the app on an emulator or device
